Biological Question Core Hypothesis
Can a protein language model predict which sites will be up- or down-regulated in PTM abundance under a specific drug treatment — using only the protein's amino acid sequence?

Post-translational modifications (PTMs) are direct effectors of cellular drug response. When a kinase inhibitor or chaperone inducer (such as Arimoclomol) is applied, it triggers cascades that alter phosphorylation states across thousands of sites. Certain proteins and sites consistently show up-regulation (increased phospho-occupancy) or down-regulation in drug-sensitive conditions.

The central question here is whether the intrinsic sequence features of a protein — as captured by a PLM trained on millions of unlabelled sequences — are sufficient to distinguish "drug-responsive" phospho-sites from "inert" ones. No drug structure, no known pathways, no prior experimental readout is given to the model at inference time. The PLM sees only residues.

If PLMs succeed, it implies that evolution has encoded PTM-regulatory context into local and global sequence patterns that language models can read. This could enable zero-shot prioritisation of candidate PTM sites for drug-response studies without performing mass-spec experiments.

PTM types investigated: The PMADS database covers 19 PTM types. In this report: Phosphorylation — Experiments 1 (WM1366), 2 (WM793), 3 (Prostate LNCaP).
Acetylation — Investigated in separate experiments using the same PLM-embedding pipeline on PMADS acetylation entries (Lys-residue context). Results not shown here but use an identical analytical framework.

Analysis Workflow Pipeline
1
Data source — PMADS database
Download curated + inferred PTM–drug–disease associations (PMADS.xlsx + Whole_DB.zip). Filter to entries with quantitative fold-change data from PRIDE-derived proteomics experiments (MaxQuant; FDR-corrected Wilcoxon, adj. P < 0.05).
2
Experiment-specific filtering
Select entries matching: PTM type = phosphorylation, cell line = WM1366, drug = Arimoclomol, genetic context = FUT4 OE. Each row represents a single phospho-site on a specific protein.
3
Binary label assignment
Sites with significant up-regulation in drug-treated conditions → class 1 (drug-responsive / sensitive). Sites that are down-regulated, unchanged, or below significance threshold → class 0 (drug-resistant / inert). A balanced train/test split (80:20) is maintained.
4
PLM embedding extraction
Four embedding strategies per model to capture different aspects of sequence context:
CenterOnly — embedding of the modified residue (phospho-Ser/Thr/Tyr) AttnPool — attention-weighted mean over full sequence MaxPool — element-wise max over all residue embeddings Hybrid (C+Attn) — concat of CenterOnly + AttnPool
5
Binary MLP classifier
Shallow MLP (2 hidden layers, ReLU, dropout) trained on 80% split with class-weighted BCE loss to handle imbalance. Hyperparameters tuned per embedding strategy.
6
Evaluation on held-out test set
Metrics: AUROC, AUPRC, Precision, Recall, F1 (at optimal threshold). Best variant per PLM selected by F1. All 12 model × variant combinations reported.
Experiment Details WM1366 · Arimoclomol
Cell Line
WM1366
Melanoma cell line derived from a primary vertical-growth-phase melanoma. Used as a model for early-stage melanoma drug response with FUT4 (fucosyltransferase 4) overexpression to study glycosylation-driven signalling.
Drug
Arimoclomol
A co-inducer of heat shock proteins (HSP70, HSP90). Amplifies the endogenous heat shock response. Investigational in neurodegenerative diseases; applied here in the context of FUT4-overexpressing melanoma to study proteostasis-driven phospho-signalling changes.
Genetic Context
FUT4 Overexpression
FUT4 (Lewis X synthase / CD15 antigen) catalyses the synthesis of Lewis X (3-fucosyl-N-acetyllactosamine). OE alters cell-surface glycosylation, affecting receptor clustering, adhesion signalling, and downstream phosphorylation cascades relevant to drug sensitivity.
PTM Type
Phosphorylation
Serine, Threonine, and Tyrosine phosphorylation sites from PMADS inferred dataset. Sites quantified by label-free quantification (LFQ) from PRIDE proteomics data. Localisation probability > 0.8; MaxQuant score > 40.
Why both phosphorylation and acetylation? Drug treatments perturb multiple PTM types simultaneously. While phosphorylation dominates kinase-inhibitor studies, acetylation (Lys) is equally important for histone remodelling and metabolic enzyme regulation. PMADS captures both, and the same PLM embedding pipeline can be applied to acetylation sites — where the modified Lys residue becomes the "centre" residue in the CenterOnly strategy and Hybrid variant.

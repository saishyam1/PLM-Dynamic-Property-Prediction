Database Description
What is PMADS?
An integrated database that systematically organises PTM–drug–disease ternary associations — i.e. PTM-centred drug responses in disease context. PTM events may modulate drug efficacy, drugs may alter PTM levels, or associations may exist without a clear causal direction.
Regulatory classes
Enhancing PTM events that improve drug efficacy.
Impairing PTM events that reduce or antagonise drug efficacy.
Associated Directional mechanism unclear.
Curated data pipeline
Mined >2 million PubMed abstracts via PubTator entity recognition + dependency parsing (Stanza) + expert manual review across 11 species. Confidence scores 2–5 mapped to High / Moderate / Low.
Inferred data pipeline
50 PRIDE proteomics datasets processed via MaxQuant (LFQ, TMT, SILAC). Sites filtered by score >40, localisation probability >0.8, FDR-corrected Wilcoxon test (adjusted P < 0.05).
Citation
Zheng J, et al. (2026) PMADS: an integrated database of curated and proteomics-inferred associations between protein post-translational modifications and drug sensitivity. Nucleic Acids Research. 54(D1):D1569–D1578.
DOI: 10.1093/nar/gkaf1033
Data used in this study
Downloaded PMADS.xlsx (core curated dataset) and Whole_DB.zip (full database including manually calibrated literature profiles, PTM annotated profiles, disease annotated profiles, protein and drug annotated profiles). Filtered to phosphorylation events in three disease / drug contexts for binary classification (drug-sensitive vs drug-resistant phosphoprotein sites).

Classification task (sensitive vs resistant)
Task design: For each experiment, protein-level embeddings (768-dim Ankh / 1280-dim ESM2 / 1024-dim ProtT5) are extracted via four pooling / fusion strategies: AttnPool MLP, MaxPool MLP, CenterOnly MLP (embedding of the phospho-site residue only), and Hybrid (C+Attn) (centre + attention-pool concatenation). A binary MLP classifier is trained to predict drug sensitivity from phosphorylation status. Metrics reported on held-out test sets.
Melanoma · FUT4 OE · Arimoclomol — WM1366 cell line
Melanoma cell line WM1366 with FUT4 (fucosyltransferase 4) overexpression under Arimoclomol (Ari) drug treatment. Phosphorylation profiles from PMADS inferred dataset, representing sites differentially phosphorylated in drug-sensitive vs drug-resistant conditions.

Melanoma · FUT4 OE · Arimoclomol — WM793 cell line
Same drug–PTM context as WM1366 but in the independent WM793 melanoma cell line. Used as a replication experiment to assess whether PLM predictions generalise across different melanoma backgrounds with the same drug treatment.

Prostate Cancer · LNCaP · Palbociclib
Prostate cancer LNCaP cells treated with Palbociclib (CDK4/6 inhibitor). Phosphorylation data from PMADS inferred module (PRIDE-derived). Binary classification of phospho-sites associated with drug sensitivity vs resistance in this hormone-sensitive prostate cancer model.
Prostate Cancer LNCaP Palbociclib CDK4/6 inhibitor Phosphorylation
Ankh 768-dim
Ankh-base protein LM. Embeddings per phospho-site via centre residue extraction + max/attn pooling over the full protein sequence.
ESM2 1280-dim
ESM2-650M (fair-esm). Per-residue representations extracted; central phospho-site residue embedding + full-sequence pooling variants.
ProtT5 1024-dim
ProtT5-XL-UniRef50. Embeddings from NFS cache. Same four pooling architectures as Ankh and ESM2 for fair cross-model comparison.

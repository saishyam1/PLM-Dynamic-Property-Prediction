Database Description
What is PMADS?
An integrated database that systematically organises PTM–drug–disease ternary associations — i.e. PTM-centred drug responses in disease context. PTM events may modulate drug efficacy, drugs may alter PTM levels, or associations may exist without a clear causal direction.
Regulatory classes
Enhancing PTM events that improve drug efficacy.
Impairing PTM events that reduce or antagonise drug efficacy.
Associated Directional mechanism unclear.
Curated data pipeline
Mined >2 million PubMed abstracts via PubTator entity recognition + dependency parsing (Stanza) + expert manual review across 11 species. Confidence scores 2–5 mapped to High / Moderate / Low.
Inferred data pipeline
50 PRIDE proteomics datasets processed via MaxQuant (LFQ, TMT, SILAC). Sites filtered by score >40, localisation probability >0.8, FDR-corrected Wilcoxon test (adjusted P < 0.05).

Data used in this study
Downloaded PMADS.xlsx (core curated dataset) and Whole_DB.zip (full database including manually calibrated literature profiles, PTM annotated profiles, disease annotated profiles, protein and drug annotated profiles). Filtered to phosphorylation events in three disease / drug contexts for binary classification (drug-sensitive vs drug-resistant phosphoprotein sites).
Biological Question & Workflow Core Hypothesis
Central Question

Can a protein language model predict which sites will be up- or down-regulated in PTM abundance under a specific drug treatment — using only the protein's amino acid sequence?

The model receives no drug structure, no pathway knowledge, no cell-line identity — only raw residues. If PLMs succeed, it means evolution has encoded PTM-regulatory grammar into sequence-local and long-range patterns that language models can read, enabling zero-shot prioritisation of drug-responsive PTM sites without mass-spec experiments.

PTM types investigated: Phosphorylation Ser/Thr/Tyr — used in all 3 experiments here (kinase-signalling cascades triggered by Arimoclomol and Palbociclib). Acetylation Lys — investigated in separate experiments using the identical pipeline on PMADS acetylation entries; the modified Lys becomes the "centre" residue. Results not shown in this report.

Workflow (shared across all 3 experiments):

  1. PMADS filtering — select entries by drug + cell-line + PTM type, retaining sites with FDR-corrected significance (adj. P < 0.05, MaxQuant score > 40, localisation probability > 0.8)
  2. Label assignment — up-regulated site in drug condition → class 1 (drug-responsive); down-regulated/unchanged → class 0
  3. PLM embedding — four strategies: CenterOnly (modified residue only), AttnPool (attention-weighted sequence mean), MaxPool (element-wise max), Hybrid C+Attn (concat of CenterOnly + AttnPool)
  4. Binary MLP classifier — 2-layer MLP with class-weighted BCE loss, 80:20 train/test split
  5. Evaluation — AUROC, AUPRC, Precision, Recall, F1 on held-out test; best variant per PLM by F1

Prostate LNCaP · Palbociclib

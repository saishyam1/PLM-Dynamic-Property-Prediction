Biological Question Core Hypothesis
Can a protein language model predict which sites will be up- or down-regulated in PTM abundance under a specific drug treatment — using only the protein's amino acid sequence?

Post-translational modifications (PTMs) are direct effectors of cellular drug response. When Arimoclomol is applied to FUT4-overexpressing melanoma cells, it triggers cascades that alter phosphorylation states across thousands of sites. This experiment asks the same core question as Exp 1 (WM1366) but in an independent melanoma cell line (WM793) — serving as a replication to test whether PLM-learned sequence features generalise across different tumour backgrounds under the same drug context.

The model receives only the protein amino acid sequence — no drug structure, no cell-line identity, no prior experimental readout. If results in WM793 mirror those in WM1366, it argues that PLMs detect universal sequence-encoded phospho-regulatory grammar, not cell-line-specific artefacts.

If PLMs succeed, it implies that evolution has encoded PTM-regulatory context into local and global sequence patterns that language models can read — enabling zero-shot prioritisation of candidate PTM sites for drug-response studies.

PTM types investigated: The PMADS database covers 19 PTM types. In this report: Phosphorylation — Experiments 1 (WM1366), 2 (WM793), 3 (Prostate LNCaP).
Acetylation — Investigated in separate experiments using the same PLM-embedding pipeline on PMADS acetylation entries (Lys-residue context). Results not shown here but use an identical analytical framework.

Analysis Workflow Pipeline
1
Data source — PMADS database
Download curated + inferred PTM–drug–disease associations (PMADS.xlsx + Whole_DB.zip). Filter to entries with quantitative fold-change data from PRIDE-derived proteomics experiments (MaxQuant; FDR-corrected Wilcoxon, adj. P < 0.05).
2
Experiment-specific filtering
Select entries matching: PTM type = phosphorylation, cell line = WM793, drug = Arimoclomol, genetic context = FUT4 OE. This mirrors Exp 1 but in a biologically independent cell line to test cross-background generalisation.
3
Binary label assignment
Sites with significant up-regulation in drug-treated conditions → class 1 (drug-responsive). Sites that are down-regulated, unchanged, or below significance threshold → class 0. Balanced 80:20 train/test split.
4
PLM embedding extraction
Four embedding strategies per model to capture different aspects of sequence context:
CenterOnly — embedding of the modified residue (phospho-Ser/Thr/Tyr) AttnPool — attention-weighted mean over full sequence MaxPool — element-wise max over all residue embeddings Hybrid (C+Attn) — concat of CenterOnly + AttnPool
5
Binary MLP classifier
Shallow MLP (2 hidden layers, ReLU, dropout) trained on 80% split with class-weighted BCE loss. Hyperparameters tuned per embedding strategy.
6
Evaluation & cross-experiment comparison
Metrics: AUROC, AUPRC, Precision, Recall, F1 (at optimal threshold). Results compared to Exp 1 (WM1366) to assess cross-cell-line generalisation. Best variant per PLM selected by F1. All 12 combinations reported.
Experiment Details WM793 · Replication
Replication design: WM793 uses the exact same drug (Arimoclomol) and genetic perturbation (FUT4 OE) as Exp 1 (WM1366) but in an independent melanoma cell line. This tests whether PLM embeddings detect a drug–PTM signal that is cell-line-invariant — i.e., encoded in the protein sequence itself rather than in cell-type-specific regulatory contexts.
Cell Line
WM793
Melanoma cell line derived from metastatic tissue. Distinct genetic background from WM1366 (primary tumour). Used here to confirm that drug-responsive phospho-site predictions generalise across melanoma subtypes under the same drug and perturbation context.
Drug
Arimoclomol
Co-inducer of heat shock proteins (HSP70, HSP90). Amplifies the endogenous heat shock response. Applied here to FUT4-OE WM793 cells to compare phosphorylation remodelling with the WM1366 context.
Genetic Context
FUT4 Overexpression
Same FUT4 (Lewis X synthase / CD15) overexpression as Exp 1. Enables direct cross-cell-line comparison. FUT4-driven glycosylation changes alter receptor signalling and downstream phospho-cascades.
PTM Type
Phosphorylation
Ser/Thr/Tyr phosphorylation sites from PMADS inferred dataset (PRIDE proteomics). Same quality filters as Exp 1: localisation probability > 0.8, MaxQuant score > 40, FDR-corrected significance.

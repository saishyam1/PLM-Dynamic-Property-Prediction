Biological Question Core Hypothesis
Can a protein language model predict which sites will be up- or down-regulated in PTM abundance under a specific drug treatment — using only the protein's amino acid sequence?

CDK4/6 inhibitors such as Palbociclib block cell-cycle progression by preventing retinoblastoma protein (Rb) phosphorylation, thereby halting G1→S transition. Treatment triggers a cascade of secondary phosphorylation changes across hundreds of proteins — some are down-regulated (consistent with CDK4/6 substrate loss), others are up-regulated as compensatory responses, and still others reflect off-target effects.

This experiment asks: can PLM sequence embeddings, with no knowledge of CDK4/6 kinase motifs or cell-cycle biology, classify which phospho-sites will respond to Palbociclib? The model receives only the raw amino acid sequence of the target protein — no drug, no pathway, no cell-line context.

Notably, all three PLMs achieve AUROC > 0.79 on this dataset — markedly higher than the two melanoma experiments — suggesting that Palbociclib-responsive phospho-sites in LNCaP cells carry especially strong sequence-level discriminative signal. CDK4/6 substrate consensus motifs (S/T-P-x-K/R) may create learnable sequence patterns accessible to PLMs.

PTM types investigated: The PMADS database covers 19 PTM types. In this report: Phosphorylation — Experiments 1 (WM1366), 2 (WM793), 3 (Prostate LNCaP).
Acetylation — Investigated in separate experiments using the same PLM-embedding pipeline on PMADS acetylation entries (Lys-residue context). Results not shown here but use an identical analytical framework.

Analysis Workflow Pipeline
1
Data source — PMADS database
Download curated + inferred PTM–drug–disease associations (PMADS.xlsx + Whole_DB.zip). Filter to entries with quantitative fold-change data from PRIDE-derived proteomics experiments (MaxQuant; FDR-corrected Wilcoxon, adj. P < 0.05). Prostate data also cross-referenced with decryptM dataset for kinase-inhibitor phospho-responses.
2
Experiment-specific filtering
Select entries matching: PTM type = phosphorylation, cell line = LNCaP (hormone-sensitive prostate cancer), drug = Palbociclib (CDK4/6 inhibitor). Each row is a single phospho-site with a significant differential response.
3
Binary label assignment
Sites with significant up-regulation in Palbociclib-treated conditions → class 1 (drug-responsive). Down-regulated or unchanged sites → class 0. Note: the label represents phospho-site response direction, not whether the site is a direct CDK4/6 substrate. Balanced 80:20 train/test split.
4
PLM embedding extraction
Four embedding strategies per model:
CenterOnly — embedding of the modified Ser/Thr/Tyr residue AttnPool — attention-weighted mean over full sequence MaxPool — element-wise max over all residue embeddings Hybrid (C+Attn) — concat of CenterOnly + AttnPool
5
Binary MLP classifier
Shallow MLP (2 hidden layers, ReLU, dropout) trained on 80% split with class-weighted BCE loss. CenterOnly performs best on this task, likely capturing CDK4/6 consensus motif patterns at the phospho-site level.
6
Evaluation — best results across all 3 experiments
Metrics: AUROC, AUPRC, Precision, Recall, F1. Prostate LNCaP achieves the highest AUROC of the three experiments (Ankh 0.813, ProtT5 0.819), suggesting kinase-inhibitor PTM responses are more sequence-predictable than heat-shock-driven melanoma responses.
Experiment Details LNCaP · Palbociclib
Cell Line
LNCaP
Hormone-sensitive prostate adenocarcinoma cell line. Androgen receptor (AR) positive; widely used as a model for CDK4/6 inhibitor response in prostate cancer. Palbociclib is being evaluated clinically in combination with AR antagonists in this setting.
Drug
Palbociclib (Ibrance)
Selective CDK4/6 inhibitor. Blocks cyclin D–CDK4/6 complex activity, preventing Rb phosphorylation and halting G1→S transition. FDA-approved for HR+/HER2− breast cancer; investigational in prostate. Primary targets: Rb (T356, S780, S795, S807/811) and downstream effectors.
Mechanism Context
CDK4/6 inhibition → G1 arrest
CDK4/6 substrates cluster around a consensus motif (S/T-P-x-K/R). These motifs may be recognisable by PLMs as structurally distinctive regions, potentially explaining the higher AUROC in this experiment vs the melanoma heat-shock experiments.
PTM Type
Phosphorylation
Ser/Thr/Tyr phosphorylation from PMADS inferred module (PRIDE proteomics + decryptM kinase-inhibitor phospho-atlas). Localisation probability > 0.8, MaxQuant score > 40, FDR-corrected significance (adj. P < 0.05).
Why higher AUROC in Prostate? CDK4/6 kinases phosphorylate substrates at well-defined consensus motifs (S/T-P). This local sequence pattern may be directly learnable by PLM attention heads — a site in a -(S/T)-P-x-K/R- context will consistently embed differently from a non-consensus site. In contrast, the Arimoclomol (HSP co-inducer) context in melanoma triggers broader, more diffuse phospho-remodelling without strict consensus sites, making it harder for sequence-only models. This pattern suggests that PLMs are most powerful when drug-responsive PTM sites have sequence-recognisable kinase recognition motifs.

Interpretation: All three PLMs achieve AUROC > 0.79 — the strongest results across all three experiments. ProtT5 CenterOnly leads on both AUROC (0.819) and F1 (0.641), while Ankh Hybrid achieves the highest absolute AUROC among Ankh variants (0.813). The dominance of CenterOnly variants (ProtT5, ESM2) suggests that the local sequence context directly around the phospho-site (Ser/Thr/Tyr) encodes the key discriminative signal — consistent with CDK4/6 substrate consensus motifs. The lower F1 vs AUROC ratio (AUROC ≈ 0.82, F1 ≈ 0.60) indicates that while ranking is excellent, binary decision boundaries remain imperfect due to class imbalance and biological noise in drug-response labelling.

Experiment Setup Details
Cell Line
LNCaP
Hormone-sensitive prostate adenocarcinoma (AR+). Widely used model for CDK4/6 inhibitor response; Palbociclib under clinical evaluation with AR antagonists.
Drug
Palbociclib (Ibrance)
Selective CDK4/6 inhibitor. Blocks cyclin D–CDK4/6, prevents Rb phosphorylation, arrests G1→S. FDA-approved for HR+/HER2− breast cancer.
Mechanism
CDK4/6 inhibition → G1 arrest
CDK4/6 substrates cluster around S/T-P-x-K/R consensus motifs — potentially recognisable by PLMs, explaining higher AUROC vs melanoma experiments.
PTM Type
Phosphorylation
Ser/Thr/Tyr from PMADS inferred + decryptM kinase-inhibitor phospho-atlas. Localisation prob. >0.8, score >40, adj. P <0.05.
Why higher AUROC? CDK4/6 substrates carry a well-defined consensus motif (S/T-P). PLM attention heads can learn this local pattern, giving strong sequence-level discriminative signal. In contrast, Arimoclomol-driven melanoma phospho-remodelling lacks strict consensus sites.
